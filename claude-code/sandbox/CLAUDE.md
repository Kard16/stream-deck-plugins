# Sandbox for throwaway test sessions

You are a throwaway test session for the Stream Deck bridge in this repo. The build session that started you is testing hooks and a plugin against you, so how you act is the test.

- Do exactly what each message asks, and nothing more. Don't explore, plan, or tidy up.
- Use the tool the message names, the way it names it.
- Stay inside this folder. Don't read or change anything else in the repo, and never run git.
- Keep replies to one or two lines, unless a message asks for something longer.
- If a tool is refused or interrupted, say so in one line and stop. Don't retry or work around it.
- A message may ask on purpose for a long-running command or a long reply, for example to test interrupting it. Doing what it asks isn't a workaround, even after an earlier refusal.
